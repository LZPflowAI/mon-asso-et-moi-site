Assistance

Une question, un problème ? Les réponses aux questions fréquentes sont ci-dessous. Sinon, écrivez-nous.

Nous contacter

Par e-mail : contact@mon-asso-et-moi.fr

Indiquez le nom de votre association, l'appareil utilisé (Android, iPhone, Mac ou Windows) et ce qui se passe. Pour une question sur vos cours, votre forfait ou vos paiements, contactez d'abord votre association : c'est elle qui gère ces informations.

Questions fréquentes

Je ne reçois pas le code à 6 chiffres

Vérifiez le dossier « Spam » ou « Indésirables » de votre messagerie, puis l'adresse saisie. Le code peut mettre une minute à arriver. Vous pouvez en demander un nouveau après quelques instants.

J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez « Mot de passe oublié ? ». Un code vous est envoyé par e-mail pour choisir un nouveau mot de passe.

Comment rejoindre mon association ?

Créez votre compte, puis touchez « J'ai un code d'invitation ou de parrainage » et saisissez le code donné par votre association. Vous pouvez aussi envoyer une demande d'adhésion depuis l'app. Le bureau de l'association l'accepte ensuite.

Mon enfant a moins de 15 ans

Un enfant de moins de 15 ans n'a pas de compte personnel. Un parent l'inscrit depuis son propre compte (« Inscrire un enfant ») et suit son dossier.

Je ne vois pas une page ou une information

Ce que chacun voit dépend des droits réglés par le bureau de l'association. Demandez-lui si vous pensez qu'il vous manque un accès.

Windows affiche une alerte de sécurité à l'installation

Windows prévient quand une application est récente. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Ensuite, les mises à jour s'installent depuis l'app.

Comment supprimer mon compte ?

Dans l'app : « Mon profil », puis « Supprimer mon compte ». Ou depuis ce site, sans l'app : supprimer mon compte.
